DODGE v2

수정 사항
1. 난이도 선택
   - 쉬움: 초기 장애물 3개
   - 보통: 초기 장애물 5개
   - 어려움: 초기 장애물 8개

2. 속도
   - 기존 기본 장애물 속도 120px/s를 1.5배 적용
   - 쉬움 기준 속도 = 180px/s
   - 보통 = 쉬움보다 1.25배
   - 어려움 = 쉬움보다 1.55배

3. 장애물 조준
   - 장애물 생성 순간 플레이어의 현재 위치를 목표로 방향을 계산합니다.
   - 따라서 플레이어가 움직여도 직선형은 생성 당시 목표 방향으로 진행합니다.

4. 장애물 종류
   - 직선형: 현재 플레이어 위치를 향해 직선 이동
   - S자형: 현재 플레이어 위치 방향으로 진행하며 S자 궤적
   - 유도형: 이동 중에도 매 프레임 플레이어의 현재 위치를 추적

5. 등장
   - 시작: 직선형 중심
   - 10초 이후: S자형 등장
   - 20초 이후: 유도형 등장

6. 기존 기능 유지
   - 30초 생존 CLEAR
   - 충돌 GAME OVER
   - 점수 / 생존시간
   - 재시작 / 난이도 재선택
   - Particle / Screen Shake / Web Audio
   - WASD / 방향키 이동

실행:
압축 해제 후 index.html을 브라우저에서 열면 됩니다.

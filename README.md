# DODGE

날아오는 탄막을 피해 30초 동안 생존하는 캐주얼 액션 게임입니다.

## 실행 방법

다운을 받고 `index.html`을 브라우저에서 열면 바로 시작할 수 있습니다.

## 조작법

| 동작 | 키 |
|---|---|
| 이동 | `W` `A` `S` `D` 또는 방향키 |
| 일시정지 / 재개 | `ESC` (또는 HUD의 ⏸ 버튼) |

- 화면(탭) 포커스를 벗어나면 자동으로 일시정지됩니다.
- 목표: 화면 중앙의 작은 원(히트박스)으로 탄막을 피하며 30초간 생존하세요.

## 난이도

- **쉬움 / 보통 / 어려움**: 장애물 수와 속도가 단계적으로 올라갑니다.
- **도전**: 1단계부터 시작해 30초를 버틸 때마다 자동으로 다음 단계로 넘어가며 끝없이 어려워집니다.
  - 도전 중 죽으면 그 단계가 기록되고, 다음에 다시 도전할 때 **이어하기**로 그 단계부터 바로 시작할 수 있습니다.
  - 시작 화면에 지금까지 도달한 최고 단계가 표시됩니다.

## 기능

- **기록 저장**: 최근 플레이 결과(최근 20판)와 도전 모드 최고 단계가 브라우저에 자동 저장되어 다음 접속 시에도 유지됩니다.
- **일시정지**: `ESC` 또는 포커스 이탈 시 자동으로 멈추고, 언제든 이어서 플레이할 수 있습니다.
- **효과 설정**: 🔇 음소거, 🌀 움직임 줄이기(화면 흔들림·파티클 감소)를 켜고 끌 수 있으며 설정도 저장됩니다.

## 장애물 종류

- **직선형**: 생성 시점의 플레이어 위치를 향해 직선으로 이동
- **S자형**: 진행 방향을 유지하며 S자로 흔들리듯 이동 (10초 이후 등장)
- **유도형**: 이동 중에도 계속 플레이어를 추적 (20초 이후 등장)

DODGE v2

수정 사항
1. 난이도 선택
   - 쉬움: 초기 장애물 3개
   - 보통: 초기 장애물 5개
   - 어려움: 초기 장애물 8개

2. 속도
   - 기존 기본 장애물 속도 120px/s를 1.5배 적용
   - 쉬움 기준 속도 = 180px/s
   - 보통 = 쉬움보다 1.25배
   - 어려움 = 쉬움보다 1.55배

3. 장애물 조준
   - 장애물 생성 순간 플레이어의 현재 위치를 목표로 방향을 계산합니다.
   - 따라서 플레이어가 움직여도 직선형은 생성 당시 목표 방향으로 진행합니다.

4. 장애물 종류
   - 직선형: 현재 플레이어 위치를 향해 직선 이동
   - S자형: 현재 플레이어 위치 방향으로 진행하며 S자 궤적
   - 유도형: 이동 중에도 매 프레임 플레이어의 현재 위치를 추적

5. 등장
   - 시작: 직선형 중심
   - 10초 이후: S자형 등장
   - 20초 이후: 유도형 등장

6. 기존 기능 유지
   - 30초 생존 CLEAR
   - 충돌 GAME OVER
   - 점수 / 생존시간
   - 재시작 / 난이도 재선택
   - Particle / Screen Shake / Web Audio
   - WASD / 방향키 이동

v3 추가 기능
=================================================
1. 저장(기록) 기능 + 도전 난이도 + 이어하기
   - localStorage(js/storage.js)만 사용, 로그인/계정 없음.
   - "어려움" 옆에 "도전" 난이도 추가.
     도전 모드는 1단계부터 시작해 30초를 버틸 때마다
     자동으로 다음 단계로 넘어가며 계속 어려워집니다
     (장애물 수 / 속도 / 스폰 간격이 단계마다 증가).
   - 규칙: 도전 N단계에서 사망(또는 중간에 나가기)하면
     그 시점의 단계 N이 기록으로 저장되고, 다음에 "도전"을
     다시 시작할 때 시작 화면에서 "이어하기 · N단계부터"를
     선택하면 그 단계부터 바로 다시 시작할 수 있습니다.
     ("처음부터 · 1단계"도 항상 선택 가능)
   - 시작 화면의 도전 버튼에 지금까지의 최고(=이어하기) 단계가
     표시됩니다.
   - 모든 판(일반/도전 공통)의 결과를 최근 20개까지
     기록에 남기고, 시작 화면의 "최근 기록 보기"에서
     확인할 수 있습니다. 개인정보/비밀값은 저장하지 않습니다.
   - 저장값이 없거나(최초 실행) 손상되어(JSON 파싱 실패 등)
     있어도 게임은 멈추지 않고 기본값(최고 0단계, 빈 기록,
     기본 효과 설정)으로 정상 시작합니다.

2. 디자인: 난이도 선택 / 조작 안내 영역 분리
   - 시작 화면에서 "난이도 선택" 카드와 "조작 안내" 카드를
     서로 다른 테두리 색/제목으로 구분된 별도 영역으로 분리.

3. 일시정지 기능
   - 플레이 중 ESC 키를 누르면 일시정지/재개가 토글됩니다.
   - 브라우저 탭/창 포커스를 벗어나면 자동으로 일시정지됩니다.
   - 일시정지 중에는 타이머/장애물/점수가 멈추고,
     재개 버튼(또는 ESC)을 누르면 그대로 이어집니다.
   - HUD의 ⏸ 버튼을 눌러도 동일하게 동작합니다.

4. 효과 설정: 음소거 / 움직임 줄이기
   - 조작 안내 카드 하단의 체크박스로 켜고 끌 수 있습니다.
   - 음소거: 켜면 이후 효과음이 재생되지 않습니다.
   - 움직임 줄이기: 켜는 즉시 현재 화면 흔들림이 멈추고
     파티클 수가 줄며, 이후 발생하는 흔들림/파티클도
     대폭 줄어듭니다.
   - 두 설정 모두 localStorage에 저장되어 다음 접속 시에도
     유지됩니다.

5. 캐릭터 커스터마이즈 (js/customize.js)
   - 시작 화면에 "캐릭터 커스터마이즈" 카드 추가.
   - 프리셋 5종(시안/마젠타/라임/앰버/바이올렛) 중 클릭으로 선택,
     또는 8x8 도화지에 8색 팔레트로 직접 그려서 "이 캐릭터 사용"
     버튼으로 적용 가능. "지우기"로 도화지 초기화.
   - 선택한 외형(appearance)은 localStorage에 저장되어 다음
     접속 시에도 유지되며, 저장값이 손상된 경우 기본(시안 프리셋)
     으로 안전하게 복구됩니다.
   - 카드 상단에 "현재 캐릭터: OOO 적용됨" 상태 표시줄이 항상
     떠 있어 지금 무엇이 적용된 상태인지 바로 확인 가능.
   - "이 캐릭터 사용" / "지우기" / "기본형으로" 버튼은 클릭하면
     잠깐(1.1초) 초록색으로 "적용됨 ✓" 등 문구가 바뀌어 실제로
     반영됐는지 눈으로 바로 확인할 수 있습니다.
   - "기본형으로" 버튼: 커스텀으로 그렸던 것과 무관하게 즉시
     기본(시안 프리셋) 캐릭터로 되돌리고 저장까지 함께 처리.
   - 히트박스(원)는 player.js에서 스킨과 완전히 분리되어 항상
     동일하게 그려지며, 이번 기능 추가로 변경되지 않았습니다.

6. 접이식(아코디언) UI (js/collapsible.js)
   - "조작 안내"와 "캐릭터 커스터마이즈" 카드는 기본적으로
     접혀 있으며, 제목을 클릭하면 펼쳐지고 다시 클릭하면 접힘.
   - 세로 공간을 아끼기 위한 변경으로, 두 카드를 전혀 펼치지
     않아도 난이도 선택 + GAME START만으로 바로 플레이 가능.
   - 커스터마이즈를 한 번도 열지 않아도 기본값(시안 프리셋
     삼각형 캐릭터)으로 정상 플레이됨 — 별도 방문 불필요.
   - 카드를 펼쳤을 때 내용이 game-wrap 높이를 넘기면(화면이
     좁은 경우 등) 잘려서 안 보이는 대신, 시작 화면 영역 자체가
     세로 스크롤되어 GAME START 버튼까지 항상 도달 가능함.
     펼치는 순간 해당 카드가 화면에 바로 보이도록 자동 스크롤됨.

실행:
압축 해제 후 index.html을 브라우저에서 열면 됩니다.

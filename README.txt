# DODGE v3 (닷지)

> **웹 기반 실시간 탄막 회피 액션 게임**  
> 날아오는 다양한 궤적의 장애물을 피하고 30초 동안 생존하거나, 끝없이 강해지는 도전 모드에서 자신의 한계 단계에 도전하세요!

 **플레이 링크**: [https://aleph-project-dodge.vercel.app](https://aleph-project-dodge.vercel.app)

---

##  게임 소개

**DODGE**는 플레이어를 정조준하며 쏟아지는 장애물을 정밀한 컨트롤로 회피하는 웹 브라우저 기반 2D 아케이드 게임입니다.  
`v2`의 조준 및 다변화된 궤적 시스템을 기반으로, `v3`에서는 **무한 단계 도전 모드**, **로컬 스토리지 데이터 영속화**, **8x8 픽셀 캐릭터 커스터마이징**, **접이식(Accordion) UI** 및 **접근성/효과 설정**이 대폭 확장되었습니다.

---

##  조작 가이드

| 입력 키 | 동작 |
| :--- | :--- |
| `W`, `A`, `S`, `D` / `방향키` | 플레이어 이동 (8방향 정밀 이동) |
| `ESC` / HUD `⏸` 버튼 | 게임 일시정지(Pause) / 재개(Resume) |
| `마우스 클릭` | UI 선택, 픽셀 도화지 드로잉 |

>  **스마트 일시정지**: 플레이 중 브라우저 탭을 벗어나거나 포커스를 잃으면 자동으로 일시정지되어 불의의 피격을 방지합니다.

---

##  난이도 & 게임 모드

### 1. 일반 난이도 (30초 생존 미션)
* **쉬움 (Easy)**: 초기 장애물 **3개**, 기준 속도 **180 px/s** (v1 대비 1.5배)
* **보통 (Normal)**: 초기 장애물 **5개**, 쉬움 대비 속도 **1.25배** (~225 px/s)
* **어려움 (Hard)**: 초기 장애물 **8개**, 쉬움 대비 속도 **1.55배** (~279 px/s)

### 2. 무한 도전 모드 (Challenge Mode) `v3 NEW`
* 1단계부터 시작하여 **30초를 버틸 때마다 자동으로 다음 단계로 진입**합니다.
* 단계가 올라갈수록 **장애물 개수, 비행 속도, 스폰 주기**가 점진적으로 가속됩니다.
* **이어하기(Check-point)**: 도전 중 도달했던 최고 단계($N$)가 로컬에 기록되어, 시작 화면에서 `이어하기 · N단계부터` 또는 `처음부터 · 1단계`를 선택해 재도전할 수 있습니다.

---

## 🚀 장애물 조준 & 궤적 알고리즘

모든 장애물은 스폰되는 찰나의 **플레이어 좌표를 목표점으로 정조준**하여 벡터를 산출합니다.

* **직선형 (Linear)**: 생성 당시 조준된 방향을 향해 일정한 속도로 직진 (0초부터 등장)
* **S자형 (Sinusoidal)**: 목표 진행 방향 축을 기준으로 좌우 사인파 진동 궤적을 그리며 돌진 (10초 이후 등장)
* **유도형 (Homing)**: 플레이어의 실시간 위치를 매 프레임 재추적하며 궤도를 수정 (20초 이후 등장)

##  v3 주요 업데이트 상세

### 1. 로컬 저장소 연동 (`storage.js`)
* **무계정 / 무서버 영속화**: `localStorage`를 활용하여 최고 도전 단계, 게임 설정, 최근 전적을 보존합니다.
* **최근 전적 20회 보존**: 최근 20게임의 결과를 '최근 기록 보기'에서 열람할 수 있습니다.
* **무결성 방어 (Fault-tolerant)**: 데이터 손상 시에도 기본값으로 안전 복구(Fallback)되어 게임이 멈추지 않습니다.

### 2. 8×8 픽셀 캐릭터 커스터마이저 (`customize.js`)
* **5종 컬러 프리셋**: 시안(기본), 마젠타, 라임, 앰버, 바이올렛 중 원클릭 적용.
* **커스텀 도화지**: 8×8 그리드 캔버스에 8가지 색상 팔레트로 나만의 도트 스킨을 직접 드로잉.
* **스킨-피격 판정 분리**: 외형 스킨과 무관하게 플레이어의 실제 히트박스(원형 판정)는 항상 일정하게 유지됩니다.

### 3. 반응형 접이식 UI & 화면 최적화 (`collapsible.js`)
* **아코디언 카드**: '조작 안내'와 '캐릭터 커스터마이즈' 영역이 기본적으로 접혀 있어 모바일/작은 창에서도 즉시 `GAME START`에 접근 가능합니다.
* **자동 스크롤 네비게이션**: 카드를 펼쳤을 때 뷰포트를 벗어나면 화면이 자동으로 스크롤됩니다.

### 4. 접근성 & 이펙트 옵션
* **음소거 (Mute)**: Web Audio API 효과음 온/오프 제어.
* **움직임 줄이기 (Reduce Motion)**: 화면 흔들림(Screen Shake) 억제 및 파티클(Particle) 방출량을 최소화하여 시각적 피로도를 경감합니다.
